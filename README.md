Tech Stack

Getting Started
Installation

Clone the repository to your local machine:

bash
git clone https://github.com/Rick8715/Portfolio.git
cd Portfolio
Usage

Simply open index.html in your browser, or deploy it live using GitHub Pages.

Folder Structure
Portfolio/
├── index.html
├── style.css
├── script.js
└── README.md
Deployment (GitHub Pages)
Go to your repo on GitHub
Click Settings → Pages
Under "Branch," select main and /root, then Save
Your site will be live at https://rick8715.github.io/Portfolio/ within a minute or two
